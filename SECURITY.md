# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through [GitHub's security advisories](https://github.com/EymanEP/consigna/security/advisories/new).

Include what you found, how to reproduce it, and the version (`consigna --version`). You will get a reply within a week. Once a fix is released, you are credited in the advisory unless you prefer not to be.

## Supported versions

Only the latest release receives security fixes while the project is below 1.0.

## Scope

The threat model, including what Consigna deliberately does not protect against (for example plain HTTP on the LAN), is described in [docs/security.md](docs/security.md). Issues within that stated scope are the most useful reports, but anything surprising is welcome.
